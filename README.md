# AI Study Assistant 🤖📚

An AI-powered study assistant built with Python and the OpenRouter API.

## Features

- Ask questions and get AI-powered answers
- Explain difficult topics in simple language
- Summarize text into concise points
- Generate multiple-choice quizzes
- Get practical examples for concepts
- Continue conversations with context

## Technologies Used

- Python
- OpenRouter API
- OpenAI Python SDK
- python-dotenv

## How It Works

The application sends the user's request to an AI model through the OpenRouter API and displays the generated response.

The API key is stored securely in an environment variable and is not included in the public repository.
